# Snapmint Shopify React widgets

React + Webpack theme app extension with separate native React components and
Shopify blocks for product pages, collections, product cards, the cart drawer,
and the cart page.
Each Liquid block supplies product/cart context directly, so normal rendering
does not depend on merchant theme selectors.

## Build

```sh
npm install
npm run check:legacy
npm run build
shopify app dev
```

The original `9338.js` is retained byte-for-byte as
`src/legacy-engine.js` for line-level auditing. It is not imported by the
production bundle. `npm run check:legacy` verifies the exact source prefix and
audits all 137 original functions and 56 original variables, so an original
symbol cannot disappear silently.

Production uses native React modules for plan calculations, cashback, coupon
APIs, eligibility, analytics, popup/terms, express checkout, product variants,
PDP quantity/add-to-cart, Shopify cart loading, and live cart updates. The
generated bundle contains no legacy runtime chunk.

## Merchant configuration

Every block supports:

- Merchant ID and plan JSON
- Full `snapOptions` override JSON
- A remote merchant configuration JSON URL; `{merchant_id}` in the URL is
  replaced with the block's merchant ID

The remote response can be either the `snapOptions` object itself or
`{ "snapOptions": { ... } }`.

## Migration status

- Collection/category and product-card: native React.
- PDP: native React, including quantity, variant, popup and optional add-to-cart.
- Mini-cart/cart drawer: native React, including live Shopify cart refresh.
- Cart page: native React with its own theme block.
- Shared popup: native React plans, terms, cashback, coupons, eligibility and
  express checkout; cart checkout sends every cart product.

## Verification

```sh
npm run verify
```

This builds the production bundle and runs isolated browser integration tests
for collection/category, PDP, cart drawer, cart page, popup, coupons,
eligibility, checkout payloads, variants, quantities, add-to-cart, delivery
fees, and live cart changes.

Copy this extension into an existing Shopify CLI app, or run `shopify app init`
in the repository and use the Partner app credentials generated by Shopify.
Those credentials are intentionally not hard-coded in this project.
